1. System Overview

Three specialized applications engineered for Shivalaya Panache resort operations

The Shivalaya Panache Restaurant Management Suite is a modern 3-tier application ecosystem designed specifically for luxury resort hospitality. Each application is tailored to its specific user persona:

🛎️ Customer Menu App

Public-facing digital menu for hotel guests. Allows browsing by category, filtering Veg/Non-Veg, searching items, and placing Room Service, Dine-In, or Takeaway orders.

→ Guest Facing (No login required)

🖥️ Front Desk Dashboard

Receptionist command center with PIN authentication, multi-staff profiles, live order kanban queue, order detail drawers, ticket printing, and full English/Hindi mode.

→ Receptionist / Staff (PIN Protected)

📊 Owner's Ledger

Management dashboard with revenue analytics, room-wise Guest Folio ledger, live menu item editor, and full order history tracking.

→ Owner / Manager (PIN Protected)

🔗

4. Customer Menu Model

Guest-facing digital ordering interface

🍽️ Menu Features
  • 🏷️
    Category Tabs — Browse 20+ sections (Breakfast, Soups, Indian Main, Italian, Kumaoni, Desserts, Beverages)
  • 🔍
    Real-time Search — Search dishes instantly by keyword
  • 🌿
    Veg / Non-Veg Filter — Filter dishes by dietary preference
  • 💰
    Clear Pricing — Items display prices in ₹ with veg/non-veg indicator dots
🛒 Ordering Flow
  • ➕
    Quantity Stepper — Tap + / – to add items directly to cart
  • 🛒
    Sticky Cart Bar — Shows live item count and total at screen bottom
  • 📦
    Service Selector — Room Service (with Room #), Dine-In (Table #), or Takeaway
  • ✏️
    Special Instructions — Add custom notes (e.g., "Extra spicy")
  • ✅
    Order Checkout Modal — Instant confirmation screen with order summary
🖥️

5. Front Desk Dashboard Model

Receptionist command center with order management & Hindi support

📋 Dashboard Features
  • 👥
    Multi-Staff Profile Picker — Switch between receptionists seamlessly
  • 🔢
    PIN Pad Login — Touchscreen-friendly PIN pad with shake error animation
  • 📊
    Kanban Order Queue — Visual order pipeline: New → Confirmed → In Kitchen → Ready → Served
  • 🔎
    Order Detail Drawer — Tap any order to view full items, guest info, table/room, notes, and action buttons
  • 🖨️
    Thermal Ticket Printing — Print formatted Kitchen Tickets and Guest Bills directly from browser
  • 🔔
    Notification Center — Bell dropdown listing recent order alerts
  • 🧑‍💼
    Duty Status Control — Set status to On Duty, On Break, or Off Duty
📊

6. Owner's Ledger Model

Management suite for analytics, room folios, and menu controls

📈 Analytics Overview

Track today's revenue, total order volume, completed/cancelled breakdown, average order value, and top-selling dishes.

🏨 Guest Folio Ledger

Room-by-room billing history. Click any room (e.g., Room 101, 104) to see every food order billed to that room with printable folio support.

✏️ Live Menu Editor

Full control to update dish names, prices, categories, availability, or add new items directly from the dashboard.
